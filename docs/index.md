# 原生状态，完整表格界面

ApexTableReact 为商品、订单和配置列表提供紧凑、可定制的 React 表格。保留 TanStack Table v9 的列、实例、状态和 updater，增加业务列表需要的布局与交互。

[组件演示](/components/apex-table) · [快速开始](/guide) · [API](/api)

业务创建实例，负责请求、缓存、身份和权限；TanStack 管理模型与状态；Apex 管理表头、虚拟表体、控件、布局、滚动和焦点。

提供浅色主题、独立结构 CSS 和可替换控件。只加载结构 CSS 也能得到正确布局，再接入公司视觉系统。

当前 `apex-table-react@0.1.0-rc.0` 为本地候选。尚未完成正式发布验收。
